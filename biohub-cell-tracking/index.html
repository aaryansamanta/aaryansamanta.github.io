Algorithm provenance and interpretation

The uploaded Biohub-Silver-cell-tracking-getting-started-w-nearest-neighbor(1).ipynb computes 3D centroids, converts voxel positions to physical coordinates using [1.625, 0.40625, 0.40625] µm/voxel (Z, Y, X), uses SciPy's linear_sum_assignment for globally optimal one-to-one matching between consecutive frames, and rejects links above 15 µm. This browser demo implements the latter three steps, including an equivalent minimum-cost Hungarian assignment, on supplied or synthetic centroids. The notebook's Zarr/Blosc2 image reading, smoothing, percentile thresholding, and connected-component detection are not reproduced here.

The separate geometric-fusion notebook uses a more complex CUDA-dependent pipeline and is not represented by this lightweight demo. Synthetic detections are educational test inputs, not competition images or validation results. The notebook's provenance and any third-party code should be attributed accurately before use in admissions materials.
