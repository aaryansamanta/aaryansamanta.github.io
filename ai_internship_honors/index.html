PROJECT DOCUMENTATION

Original work and demo scope

What the original notebook does

Loads chest X-ray folders for train/validation/test, resizes and rescales images, builds a 3-stage CNN, trains using TensorFlow/Keras, evaluates predictions, and displays accuracy/loss learning curves.

What this website executes

Client-side image resize and pixel normalization preview, interactive network-layer explanations, and recalculated metrics from the report's published confusion matrices.

What this website does not do

It does not run TensorFlow training, load model weights, predict an uploaded X-ray's diagnosis, or reproduce the original experiment's test set. To reproduce training, use the linked original notebook with the appropriate chest X-ray dataset.

Ethics and attribution

Educational research demonstration only. Not a medical device. Avoid uploading identifiable patient images. The original student notebook and internship documents are provided as source materials; the browser companion is a separate implementation.
