03 / METHOD

Template-based modeling

The competition notebook uses RNA sequence alignment, template lookup and adaptation, structural constraints, and five-coordinate-set submission formatting alongside a Protenix inference pathway. This browser experiment executes the lightweight alignment and template-coordinate mapping concepts; it does not run the Protenix neural network or Kaggle inference pipeline.

04 / INTERPRETATION

What the visualization shows

Each point represents one C1′ atom. Matched residues inherit aligned template coordinates. Unmatched target residues are interpolated or extrapolated. Four additional coordinate sets apply small deterministic illustrative perturbations; they are not independent learned predictions or validated folding results.
