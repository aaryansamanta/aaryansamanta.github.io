CODE & REPRODUCIBILITY

What this browser demo executes

The source notebook defines a rule-based Mega Lucario ex baseline (exp00014_20260617_202758) using the official competition’s legal-option API. It writes main.py and deck.csv and packages a submission.tar.gz with the official cg SDK.

This page ports selected, directly inspectable Python scoring rules: the Crustle wall attack guard, active-choice scoring, search-to-hand scores, trainer priorities, and the low-deck cutoff. The browser cannot execute the original cg simulator or reproduce full games without that runtime.

Notebook specifics: MEGA_BRAVE = 983; LOW_DECK_COUNT = 10; Crustle card ID 345; Mega Lucario ex ID 678; Hariyama ID 674. The baseline explicitly avoids Mega Lucario ex attacks into Crustle and preserves a non-ex Hariyama route.

The local matchup table is shown as reported, with no invented battle replays or claims of full engine parity.
