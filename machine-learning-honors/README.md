# Legend College Preparatory — Machine Learning Honors

## Diabetes Prediction with Machine Learning

A video-only GitHub Pages presentation of the Machine Learning Honors capstone.

### Publish
1. Upload `index.html` and `Capstone_Project_Diabetes_Prediction_with_Machine_Learning 720p.mp4` to the root of a public GitHub repository.
2. In Settings → Pages, deploy from the `main` branch and `/ (root)`.
3. Open the published GitHub Pages URL to play the video.

The included `.ipynb` file is the supplied project notebook for source-code review. The website does not execute the machine-learning model.

Visual theme: airy ice blue, sky blue, and cobalt accents (distinct from the earlier dark navy/teal design).
